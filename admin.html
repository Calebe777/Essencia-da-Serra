Número de cada artesão

Este é o número padrão: todas as peças do artesão passam a encaminhar para ele. Digite com DDD — o 55 do Brasil entra sozinho.

Peças

Cada peça herda o número do artesão. Preencha o campo de número só quando aquela peça precisar de uma exceção. Peças com mais de um artesão creditado deixam você escolher quem atende.
